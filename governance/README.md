# レイヤー1・2の組み込み

このフォークに、Human × Agentの憲法・法律草案を参照する、独立したPython統制機能を追加しています。
Microsoftのコアは変更していません。追加機能の入口は [agent_factory](../agent_factory/README.md) です。

## 現在の状態

- Layer 1：[AI憲法草案 v0.1](sources/CONSTITUTION.md)
- Layer 2：[AI法律案 v0.2統合修正案](sources/OPERATING_RULES.md)
- 両方とも正式制定前の草案です。本ブランチの作成は、正式制定・権限付与・本番有効化の決定ではありません。
- 版固定した原文をモデルへの指示に含めるとともに、プログラム側で権限・承認・停止・記録を検査します。
- 現在実行できるのは、ネット接続のない模擬Toolだけです。実サービス、実データ、外部Skillsの実行は対象外です。

## 参照と変更

[manifest.json](manifest.json) は、取得元のリポジトリ、コミット、文書の版、保存したファイルのSHA-256を記録しています。
取得元からCRLFをLFへ統一し、原文の文言を保持しています。コピー中の「GitHubは変更していない」等は原文作成時の記述です。
原文に含まれる未採用案、未確定事項、条文化案の状態は保持しています。

参照元の最新変更を自動で取り込むことはありません。文書・設定が変更された場合、実行直前の検査で保留します。
更新は、本人の指示、変更差分、親条文との対応、試験結果を別途確認して行います。

## 運用設定

[research-policy.json](research-policy.json) は、研究目的、模擬Toolの許可リスト、共通の操作数・時間・委任上限を定めます。
設定の値は憲法・法律の改正ではなく、模擬研究の具体的な条件です。
本版では設定をproductionに変えると開始を拒否します。本番運用を可能にする実装は含めていません。

34項目の対応状況と残る条件は [TRACEABILITY.md](TRACEABILITY.md)、実装の信頼境界は
[BOUNDARIES.md](../agent_factory/docs/BOUNDARIES.md) を参照してください。
